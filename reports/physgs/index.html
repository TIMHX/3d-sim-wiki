方法: 三层 Bayesian 模型

1 离散材质 — Dirichlet–Categorical (闭式共轭更新)

后验预测 (观测集合 Z 后, 新观测属于材质 i 的概率) f(z = i | Z, α) = ᾱᵢ / Σⱼ ᾱⱼ ,   ᾱᵢ ← αᵢ(0) + Σ_{m: cₘ=i} λ·pₘ

λ = 每条观测的证据强度; pₘ = VLM 置信度。置信度加权 → VLM 越犹豫, 贡献越小; 多候选的置信度分布本身就是语义歧义信号。

2 连续属性 — 置信度加权矩 (流式, 不需存历史)

累加器 + 后验均值/方差 Wᵢ = Σ pₘ,   Sᵢ = Σ pₘψₘ,   Qᵢ = Σ pₘψₘ²  →  μᵢ = Sᵢ/Wᵢ,   σᵢ² = max(Qᵢ/Wᵢ − μᵢ², ε)
最终预测 = 高斯混合 (每材质一个 mode, 权重 = Dirichlet 后验) f(ψ | Z, α) = Σᵢ (ᾱᵢ / Σⱼ ᾱⱼ) · N(μᵢ, σᵢ²)

3 不确定性 — Normal–Inverse–Gamma (NIG) 先验

总预测方差分解 (key contribution) Var[ψᵢ] = E[σᵢ²] + Var[μᵢ] = β̃/(ᾱ−1) + E[σᵢ²]/κ̃
aleatoric: 类内观测噪声  ·  epistemic: 证据不足/冲突, 随高置信证据增加而下降

NIG 闭式更新: κ̃=κ+pₘ, τ̃=(κτ+pₘψₘ)/(κ+pₘ), ᾱ=α+pₘ/2, β̃=β+pₘκ(ψₘ−τ)²/(2(κ+pₘ)) — 全部在线增量, 适合 streaming 重建。

户外泛化 (RUGD / RELLIS-3D, qualitative)

单张 RGB 出材质分割 + 摩擦 + Young's modulus + 总不确定性。杂乱场景 (枯叶 vs 木头, 泥 vs 草) SAM 分不干净 → 不确定度显著升高; 均匀大表面 (砾石, 草地) → 低不确定度 + 稳定预测。即不确定性对分割质量敏感, 能如实反映证据可信度 — 这是 "calibrated" 的证据。

局限性与工程注意

论文自认: ①对 SAM 分割质量敏感 — mask 合并视觉相似材质时属性估计继承歧义, 未来方向是 VLM-guided 分割细化; ②阴影演化未建模; ③材质参数靠手工设定, 无自动赋值。
工程视角 (我的补充): ①代码未开源 — "Coming Soon" 停在论文版, 复现只能等官方 release; ②GPT-5 闭源商业 API, 每次推理花钱, 换成开源 VLM 性能未知 (无 ablation); ③SAM→GPT-5 两段误差级联, Bayesian 置信度加权只能缓解不能消除; ④"逐点"实际是"逐材质" — 先按材质类估属性再 propagate 到点, 材质分类错则点全错; ⑤评估集小 (6 摩擦点, 15 物体), 户外只有定性。

对机器人项目的意义

输出可直接映射 PMAT__muXXX: 逐点摩擦 → 区域聚合 → PMAT__mu080/mu100 材质名 → 喂 IsaacLab 摩擦解析链, 比手工标注快一个量级。这正是我们 [[physical-property-estimation-from-scans]] 调研里的核心路线之一。
不确定性 = 主动采样引导: epistemic 高估的区域就是该去实地测摩擦的地方 — 比单点估计更工程友好, 能指导"哪里值得再标一针"。
与 GaussGym 互补: GaussGym 解决"场景怎么来" (扫描 → sim 分钟级), PhysGS 解决"场景物理属性怎么标" (逐点摩擦/硬度), 合起来补上 GaussGym 自认的"资产物理参数统一"短板。
落地路径: 等官方代码 → 或参考 EVORA / Ewen et al. 自研路线, 用开源 VLM + 简化 Bayesian 融合自己搭 (VLM+RAG 方案是最快 prototype, 详见 physical-property-estimation 页)。
