Method: Two-Stage Lightweight Adaptation

Stage I Supervised fine-tuning (SFT) — channel concat + LoRA

rectified flow noise + channel-concatenated conditioning z_t = (1−t)·z_0 + t·ε,   ε ~ N(0, I)   →   ẑ_t = [z_t ; z_cond ; m]
flow matching objective (model predicts velocity field v = ε − z_0) L_FM = E[ ‖ v − v_θ(ẑ_t, t) ‖² ]

LoRA rank-64 updates <1% of parameters; VAE and base model frozen. The task is narrower than generating videos from scratch: the model only needs to learn to condition on the degraded input, so 20 paired videos suffice.

Mask What to trust, what to fix

m=1 (training views): keep untouched, prevents hallucination; m=0 (degraded frames): refine. Clean frames become anchors that propagate appearance, lighting and structure to neighbors. Without the mask the model cannot distinguish already-clean frames from mildly degraded ones, costing 1.3 dB PSNR.

Stage II Flow-DPO — pose accuracy as reward

preference optimization (Δ = L2 gap in velocity prediction between current model and SFT reference) L_DPO = −E[ log σ( −β/2 · (Δ_w − Δ_l) ) ]

reward = camera pose AUC@5° recovered by COLMAP (SuperPoint + LightGlue) from model outputs; 5 seeds sampled per scene, pairs kept when AUC gap ≥ 0.2. Fixes the "plausible per-frame but inconsistent across views" hallucination. AUC@5° 61.1 → 68.3, PSNR 17.51 → 17.65, zero inference cost.

Positioning: the first "generalist" rendering-cleanup model — no representation-specific architecture, no redesign, two orders of magnitude less data. Three contributions: representation-agnostic formulation, mask-aware conditioning, geometry-as-preference optimization.

Limitations and Engineering Notes

Stated by the paper: ① Hallucination is unavoidable — the model must invent content in unobserved regions; it only fails when invented content contradicts existing observations; ② The uncertainty analysis is preliminary (5-seed std, no systematic calibration); ③ Long trajectories are processed in 61-frame chunks, chunk-boundary consistency relies on shared anchors and has theoretical limits; ④ Evaluation centers on DL3DV large scenes.
Engineering view (our additions): ① Code not released (coming soon) — same issue as PhysGS, reproduction waits for the official release; ② Inference cost — 31 s per 61-frame clip (H100, 5 steps); a video diffusion model is inherently offline preprocessing, not online rendering; ③ Relies on mask annotation — you need to know the training-view set and poses; pose noise corrupts the mask; ④ Output resolution 480×832 may be insufficient for tasks needing high-res renders; ⑤ "20 paired videos" is workable, not optimal — full quality needs 500.

Implications for the Robot Project

Fills GaussGym's rendering-quality gap: GaussGym trains robots with a 3DGS renderer; floaters from sparse scans pollute visual policy training. FixAnything (3DGS input, PSNR 17.65 @6 views) provides offline cleanup: scan → 3DGS → render trajectory → fix → clean visual stream for training.
The sparse-point route may skip intermediate reconstruction: FixAnything shows COLMAP sparse points + video prior produce high-quality renders (19.72 PSNR @9 views). Our capture pipeline can render point trajectories and apply generative cleanup, skipping NKSR mesh / 3DGS training entirely — consistent with the conclusions in our physical-property-estimation review.
Uncertainty = rescan guidance: 5-seed std marks the regions where the model is inventing (weakly observed regions), guiding where to capture more photos, or excluding high-uncertainty regions from policy training sampling.
Complements PhysGS: PhysGS needs clean 3DGS reconstruction for accurate physical property estimation; FixAnything-cleaned renders/reconstructions can serve as enhanced input. The three reviews (GaussGym → PhysGS → FixAnything) form a closed loop: scene acquisition → physics labeling → rendering quality.
Adoption path: wait for the code release → run offline cleanup on GaussGym scan outputs (COLMAP points or 3DGS renders) → compare policy training before/after. Note that 31 s per 61 frames means batch offline, not real time.
